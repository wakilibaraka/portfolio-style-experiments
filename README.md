# Portfolio Style Experiments

This repository is dedicated to testing out various animated versions and visual styles for my interactive portfolio.

## The Strategy

Instead of building 15 separate websites, we are using a **single Next.js App Router** repository. 
Each visual style has its own dedicated route (e.g., `/vernacular`, `/minimal`, `/wabi-sabi`). 
This allows us to share underlying components and data while radically altering the layout, CSS, and animations for each style to A/B test them.

## Style Roadmap

We are building these one at a time, starting from the most chaotic/archaic ("worst") to the most refined and modern:

### Tier 1: Chaotic / Raw / Retro (The "Worst" / Ugliest)
1. **[Vernacular Web](/vernacular)** - 90s GeoCities, tiled background textures, animated GIF ornaments, hit counters.
2. **[Web Brutalism](/brutalism)** - Raw HTML, default browser materials, exposed document structure, zero decorative rendering.
3. **[Scrapbook / Mixed Media](/scrapbook)** - Torn paper edges, tape, mismatched fonts, messy collage aesthetic.
4. **[Neobrutalism](/neobrutalism)** - Bright color blocks, thick black outlines, hard offset shadows.

### Tier 2: Nostalgic / Kitsch
5. **[Y2K Digital](/y2k)** - Liquid chrome, gel, glossy plastic, iridescent blue-silver matrix palette.
6. **[Frutiger Aero / Aqua](/aero)** - Glossy grass bubbles, old Mac/Windows 7 tech, sky-blue/grass-green palettes, candy-gel controls.
7. **[Skeuomorphism](/skeuomorphism)** - Simulated real materials (leather, wood, stitched fabrics), physical lighting.

### Tier 3: Modern UI Trends
8. **[Claymorphism](/claymorphism)** - Puffy 3D buttons, Play-doh aesthetic, floating objects.
9. **[Neumorphism](/neumorphism)** - Soft buttons pushed out of the background, dual soft shadows, low contrast.
10. **[Glassmorphism / Liquid Glass](/glassmorphism)** - Frosted translucent panels, vivid backdrops, lensing and blur.

### Tier 4: Refined / Elegant
11. **[Flat Design](/flat)** - Solid 2D color fills, no simulated depth, simple glyph icons.
12. **[Minimal](/minimal)** - Extreme negative space, restricted element count, monochrome palette.
13. **[Wabi-Sabi](/wabi-sabi)** - Organic, asymmetrical layouts, natural earthy tones, embracing imperfection and transience.
