# Emmanuel Baraka Ongau — Portfolio Style Experiments

An interactive design atlas and testing laboratory showcasing 13 distinct visual and animated aesthetics for Emmanuel Baraka Ongau's legal advocacy portfolio.

🌐 **Live Website (Mobile & Desktop):**  
👉 **[https://wakilibaraka.github.io/portfolio-style-experiments/](https://wakilibaraka.github.io/portfolio-style-experiments/)**
